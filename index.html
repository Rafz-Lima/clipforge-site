ClipForge

ClipForge é uma ferramenta pessoal que roda no computador do próprio usuário. Ela transforma vídeos longos em cortes verticais e, quando o usuário pede, publica esses cortes nas contas dele no YouTube, no TikTok e no Instagram.

  • Não há servidor do ClipForge: tudo acontece no computador do usuário.
  • O acesso a cada rede usa a API oficial dela (YouTube Data API, TikTok Content Posting API e API do Instagram), só com a autorização do dono da conta.
  • Nada é publicado sem o usuário mandar: ele escolhe o vídeo, o texto e a rede.
