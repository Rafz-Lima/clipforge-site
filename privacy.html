Política de privacidade do ClipForge

Atualizada em 20 de outubro de 2026.

O que é o ClipForge

Um aplicativo pessoal que roda no computador do usuário. Não existe servidor do ClipForge: nenhum dado do usuário é enviado para nós.

O que acessamos no Google

Só com a sua autorização, o ClipForge usa duas permissões do YouTube:

  • youtube.upload: enviar para o seu canal os vídeos que você escolher publicar.
  • youtube.readonly: ler o nome, a foto e o número de inscritos do canal, para mostrar qual canal está conectado.

Como os dados são usados e guardados

  • Os dados são usados apenas para publicar os vídeos que você escolher e mostrar qual canal está conectado.
  • As credenciais de acesso ficam somente no seu computador, cifradas pelo Windows.
  • Nada é vendido, compartilhado com terceiros ou usado para publicidade.

Serviços de API do YouTube

O ClipForge usa os Serviços de API do YouTube. Ao conectar seu canal, você também concorda com os Termos de Serviço do YouTube e com a Política de Privacidade do Google.

Como remover o acesso

  • No ClipForge: Configurações › Redes sociais › Desconectar.
  • No Google, a qualquer momento: myaccount.google.com/permissions.
  • Para apagar os dados locais, exclua a pasta %LOCALAPPDATA%\ClipForge\social.
